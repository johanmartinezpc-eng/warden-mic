# Warden Mic (Fabric, Minecraft Java 26.3)

Requisitos: JDK 25, Gradle 9.4+ (o el wrapper), Fabric Loader 0.19.5+, Fabric API 0.161.0+26.3.
Compilar: `gradle build` -> el .jar queda en `build/libs/`.
Instalar: copiar el .jar a `.minecraft/mods` junto con Fabric API.

Ajustes en `WardenMic.java`: THRESHOLD, MIN_RADIUS, MAX_RADIUS, ANGER_LEVEL.
